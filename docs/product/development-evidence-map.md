# Development evidence map

This is a navigation aid for the product transition described in the
[roadmap](../ROADMAP.md), not a second work queue. Start with the roadmap's
development line. Follow only the theme touched by the current question.
Private files are working evidence, not authority over current code, data or
maintained product documents. Their headings and checkboxes may describe an
earlier execution state; compare a proposed action with the current contract.
This map does not require reading every linked plan at session startup.
